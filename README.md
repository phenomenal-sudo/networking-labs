# Networking Labs

Hands-on Cisco networking labs built in Packet Tracer while studying for CCNA and a BSc Honours in Network Engineering (University of Zimbabwe).

Each lab folder contains a README (purpose, IP addressing table, credentials, verification screenshots), the Packet Tracer file, and device configurations.

## Labs

| Lab | Topics |
|---|---|
| [01 Switch Basic Hardening](01-switch-basic-hardening/) | Initial switch configuration, enable secret, console security, SSH, login banner, ping verification |

More labs are being added: inter-VLAN routing, EtherChannel, static routing, OSPF, DHCP and wireless.
